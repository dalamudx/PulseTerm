# Windows 私有目录边界

当前实现位于 `pulse-platform::windows::PrivateDirectory`。这是安全存储的基础原语，尚未接入生产 Profile／SQLite／设置文件；目录及文件级 ACL／链接检查、精确读取和排他新建已实现；精确快照与源句柄原子命名空间替换已实现但尚未原生运行；Windows 设置适配、IPC 和实际生产纵向链仍未完成。交叉编译不计为 Windows ACL 或原生运行验收。

## 准入与生命周期

- 只接受本地固定磁盘、支持持久 ACL 的卷和有界的绝对路径；拒绝 UNC／设备路径、相对路径、点段、ADS、DOS 设备名及尾随空格／点别名。初始 UTF-16 分配和组件数量均有上限。
- 逐层打开目录，使用 `OPEN_REPARSE_POINT` 检查每一层，不跟随重解析点或卷挂载点。句柄只申请安全描述符和文件属性读取权限，不共享删除；保留祖先句柄直到对象释放。
- 所有者来自真实进程 TokenUser，不读取环境用户名。祖先所有者限当前用户、SYSTEM、Administrators 或 TrustedInstaller；非可信主体只允许读取／遍历／添加新项，不得修改或删除现有项、改 ACL 或改所有者。私有叶目录必须归当前用户、DACL 受保护，且显式赋予当前用户完整访问。
- 叶目录只允许当前用户、SYSTEM、Administrators 的生效允许 ACE；缺失／NULL／空 DACL、未知 ACE、叶目录拒绝 ACE、非可信授权及畸形 SID／ACL 全部拒绝。继承专用 ACE 不当作当前目录授权，私有叶目录也拒绝其向外部主体传播权限。TrustedInstaller 不获得私有叶目录访问。
- `create` 仅创建最后一级，父目录必须已经存在；创建调用同时传入受保护安全描述符，避免“先公开创建、再收紧权限”。已存在对象只验证，不改所有者或权限。
- `validate` 同时复核保留句柄与按原路径重新打开的64 位卷号／128 位文件 ID（不支持该查询时拒绝）、属性、所有者和 ACL。不声称完全消除 TOCTOU；当前账户和本机系统／管理员属于信任边界，ACL 变更不是原子事务。

这些 API 同步阻塞，只可放在专用线程／受监督 I/O 中使用。对象不暴露原始句柄、路径读写能力或安全描述符，也不派生 Debug／serde；错误仅包含固定码，不包含路径或 SID。目录准入不授予页面、Vault、凭据使用或执行权限。

## 平台 FFI

沿用 `overview.md` 已有规则：只有 `pulse-platform` 可使用平台 FFI。crate 默认 `deny(unsafe_code)`，只有私有 `windows::sys` 模块允许；每个不安全调用都有 SAFETY 说明。其余 crate 的 forbid 规则不变。

只复用锁文件已有 `windows-sys 0.61.2`，没有引入调查中的权限封装。Token 句柄由 OwnedHandle 回收；系统分配的描述符由 LocalFree 守卫持有。Token 缓冲按原生结构对齐、限制大小；描述符先验证自相对格式，再将原生指针转为有边界的切片；ACE／SID 解析使用安全 Rust。权限或身份变化不会触发自动修复。

## 私有文件读取与排他新建

`open_file`／`create_file` 仅接受后端选择的单个 basename；该 Rust API 未接入页面或生产存储，不提供页面路径能力。文件独立校验进程所有者、受保护 ACL、完整身份、普通文件属性和单硬链接。只读意图、设备、目录、重解析点和宽权限均拒绝，现有文件不自动修复。即便打开失败，仍复核原目录，不能把撤销后的路径错误当作缺失配置。

文件 lease 借用原目录，读取句柄不共享写入／删除，排他创建句柄不共享任何访问；不会覆盖或截断原文件。读取从零开始，调用方预算最大 1MiB，读取前后复核文件身份、长度、修改时间和 ACL；只返回精确字节，不执行 UTF-8／TOML 或应用授权解析。新建时同时设置受保护 ACL，写入前验证，写后同步文件数据；失败按原文件句柄标记删除，清理失败返回 Uncertain。panic 回收仅作尽力清理，不能代替调用方的持久化不确定性处理。

这些基础 lease API 不提供快照保存或目录掉电持久性回执。持有目标 lease 时不得替换该文件。下述独立文件槽实现快照保存原语，Windows 设置／主题／键位仍须接入原授权和不确定性合同，并通过原生验证。

## 快照保存与命名空间提交

`atomic_file(name, limit)` 选择一个后端固定文件槽。`load` 返回不含 Debug／serde 的精确快照：目录身份、basename、预算、存在状态、完整文件 ID、创建／修改／变更时间及原始字节。缺失和空文件是不同状态，快照不能跨目录、文件槽或预算使用。

同一目录内固定 `.pulse-write.lock` 以不共享读写／删除的句柄串行化协作进程。锁不存在时创建私有空文件；已存在时独立检查所有者、ACL、单链接、只读与空长度，不截断或自动修复。内部锁与暂存名称保留，不可作为文件槽选择。

`save(expected, bytes, authorize)` 在首次 I/O 前、暂存完成后及原生提交前检查调用方的同步授权谓词；回调 unwind 按撤销处理。它不重新捕获页面／Vault 代际，也不能代替上层保持原授权及 I/O 信用。撤销不能撤回已开始的原生提交，调用方仍须禁止过期回执发布，并让物理工作完成后再回收容量。已经存在且字节相同的文件只校验返回，不重建文件。

新内容写入 CSPRNG 命名的目录内私有文件，创建时设置 ACL，写后刷盘。提交前重新比较快照、复核目录／锁／暂存身份，再使用原暂存句柄的 `SetFileInformationByHandle(FileRenameInfo)` 提交；首次创建禁止替换突然出现的目标。目标已存在时采用原子命名空间替换，成功后复核新身份和精确字节。原生请求使用有界对齐缓冲、完整 UTF-16 名称，FFI 仍只在私有 `sys` 模块。

这是协作锁下的快照冲突检测，不是 Windows 提供的身份条件原子 CAS。同账户非协作修改在最终比较和改名之间仍可能竞争，不承诺完全 TOCTOU 保护。原生行为尚待 Windows 运行验证；成功只表示命名空间安装和文件数据刷盘，不声明目录掉电持久性。

提交尝试前的撤销／冲突通过原句柄回收暂存文件；回收失败返回 `Uncertain`。一旦尝试改名，原生失败、刷盘失败或提交后复核失败都返回 `Uncertain`，保留可能已发布的文件或未安装的私有暂存项，不按旧路径删除，不自动重试。调用方须重新读取并显式处理残留；本层不提供通配符清理或替代存储恢复流程。

## 验证门槛

正式入口为 `mise run check-platform`：当前宿主全目标严格 Clippy 和平台单测。Linux／macOS 只运行纯 ACL／路径策略测试；Windows 额外注册真实创建、重开、句柄阻止改名、宽权限原目录不修复、文件／缺失父目录及非法路径测试，并新增七项私有文件测试（链接／只读／宽 ACL／字节／限额／失败回收）。另增加十项文件槽／快照原生测试。Windows 专属测试不在其他平台伪装通过，不使用零测试命令作为原生证据。

Windows GNU 交叉检查可验证 FFI 签名和所有测试目标能编译，不能证明 NTFS／ACL 实际语义。CI 三平台已接入正式入口，但当前主机无 Windows／macOS 实机、仓库无 remote，远端运行结果仍待取得。在真实 Windows 测试及文件级持久化接口完成前，生产入口继续拒绝不支持的平台，不以该目录原语开放 Windows 产品流程。
