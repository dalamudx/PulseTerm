# 当前会话历史分页与冷区

工作区“历史与查找”按钮、命令面板“查找当前终端”和终端聚焦时的 Ctrl/Meta+Shift+F 共用当前窗格只读入口，打开后聚焦查询。当前屏幕可查找，不列入历史翻页。支持更早、较新、最新历史、键盘滚动、复制和 Escape 关闭；原页、窗格、视图及布局仍有效时，应用恢复原入口焦点。浏览器自身的模态焦点恢复不受此回调控制。每页最多200行、128KiB，前端只保留一页与游标，不重放历史。远端文字用textContent显示。

find加入可配置键位，默认条件为workspaceFocus && terminalFocus && !editableFocus && !modalOpen && !broadcast，保留终端Ctrl+F。可改键、禁用或恢复默认，禁用后无硬编码旁路。组合输入让路；命令选择捕获原页和view/session/layout对象身份，目标变化后拒绝旧选择。后端仍独立验证原页、窗口owner和绑定，不增加输入或执行权限。

## Linux SSH 原生补充验收

`mise run probe-workspace-ssh-settings` 版本3已通过真实 SSH 输出的跨软换行中文长查询、早期历史定位、硬换行隔离，以及退出状态7／EOF／物理流回收后的历史与主屏只读查找。结果页逐码点确认原始分解重音符号保留；跨行键盘查询不含该重音符号，组合输入不计本批验收。查找期间远端零输入、无重新认证，五条连接与GUI全部退出。版本3收据和两张截图保留在 `target/probes/`。十万行内存、搜索／停止延迟、系统IME及三平台仍开放。

## 主动停止查找

查询期间提供“停止查找”，保留当前页、匹配标记与已有导航位置。停止仅撤销本轮前端扫描代际，不强行取消已经进入后端的单次有界读取；该读取退出前继续保持 busy，拒绝新查询及分页，避免重复点击堆积原生请求。迟到成功、错误和匹配均不发布，也不读取下一批。读取结束后提示“已停止查找”，用户可明确继续原查询或输入新查询。编辑查询或选项会清除旧查询状态；关闭或换页不发布迟到反馈，终端输入与会话生命周期保持独立。

类型、Biome、双语及 27 项历史查找／分页回归通过。Chrome 使用实际弹窗和受控 IPC 验证停止屏障、迟到回复／失败、重新查找、语言切换、800px 布局及 Escape 焦点恢复；收据 `target/probes/history-search-stop-browser.json`，两张截图已审阅。此证据仅覆盖浏览器交互，原生 WebView 与实际十万行扫描停止的延迟仍待验收。现有前端 CI 自动覆盖，无新增认证矩阵。

## 冷热区

生产Session Actor保留原有近期热区，用于既有恢复流程；热区以外的主屏行转入紧凑、分块的UTF-8文本冷区。两区合计默认最多100000个物理历史行，可在设置中将“保留历史行数”设为1000～100000的整数；冷区的文本、索引及块容器容量合计受16MiB分配预算约束，此外仅有常量控制对象和有界单行／单页临时投影。它不代表整个会话或进程的内存上限。

冷区块记录私有单调行号，按块起点二分定位行；分页、字面／正则查找和自然 EOF 冻结文本共用该读取路径。前缀裁剪只移动块内起点，整块回收不要求重写其余索引；长会话在计数耗尽前重基，清历史重置计数。这些坐标不进入 IPC，也不替代公开的修订与行游标。新增块索引的容器分配仍计入原 16MiB 预算，查询的行数和字节上限保持原值。

冷块封存时仅收紧一次UTF-8字符串和行索引的多余容量，活动块仍按增长策略写入。容量计账同步扣减真实分配，原始文本、软换行标记及裁剪坐标不变。同机release十万行变长日志冷区分配由7,949,824降至5,582,448字节（29.8%），定长日志8,030,208字节不变；收据 `target/probes/history-capacity-result.json` 保留两轮前后对照的全部输入耗时。该统计包含冷区容器容量，不代表分配器驻留或整进程PSS／RSS；原内存门禁继续开放。

容量保存到[terminal].history_limit，投影v6显式携带数值和来源，v1～v5继续按原封闭形状读取。配色和容量在同一次受监督、原页复验的设置读取中冻结，GUI／CLI新建本地、密码／私钥／Agent SSH以及跳板叶终端采用该值；逐跳过程中不再读取。恢复继承回到100000行，不改其他设置。已有会话保持原容量，不增加在线缩容或输入权限。

达到行数或字节预算时从最早内容开始清理，因此宽行可能少于配置行数。页返回coldRows及truncated，界面在容量清理后明确提示。显式零历史仍关闭热区和冷区。冷区不落盘，也不承诺应用重启恢复。

采集发生在每个真实Alacritty Handler调用和resize之后，覆盖单批大量输出、普通滚动、软换行及同步输出超时刷新。先投影超出热区的主屏行，再用SDK公开接口裁剪热区；不按原始输出分行，不复制解析器，不新增vendor补丁。备用屏不进入主屏冷区，resize期间也检查保留的主屏grid。

文本保留宽字符、组合字符及物理软换行标记，去掉默认尾部空白单元格，保留显式属性空白；不提供颜色或VT恢复。既有冷区行不随窗口宽度重新排版，热区仍由SDK处理。单行超过投影预算时丢弃该行及更早冷区内容、设置裁剪提示，以保持剩余历史为连续后缀。

主屏ED3清除冷热历史，备用屏ED3不清主屏；RIS重置清除两区。ED2保持历史。冷区在运行期由Actor持有，自然EOF后转入只读文本快照，普通前端刷新继续通过当前窗口的原页授权读取。

## 读取与一致性

SessionHandle::history_page在Actor串行边界读取冷热区，返回十进制修订、总行数、冷区行数、裁剪标记、起止游标、文本和换行标记。后续翻页要求原修订；输出、清历史或布局改变使游标过期。对话框保留已显示内容并提示显式读取最新历史，不自动重试或重连。

SessionRegistry先验证当前PageLaunchScope、窗口owner和绑定，读取后再次验证相同generation。读取与capture共享互斥；不授予会话选择、输入、resize或ACK额度，不修改终端流或PTY。workspace_terminal_history_page仍只接受当前WebView上下文和nonce，要求游标／修订同时存在，使用固定错误码和一秒等待上限。

前端固定打开时的视图、焦点会话和布局标识；页面退出、视图／焦点变更或关闭后丢弃迟到结果。同修订翻页同时校验总行数和冷区元数据，拒绝混页。

## 保留历史字面查找

历史对话框支持字面查找、区分大小写、前后定位和匹配行段高亮。查找范围显式选择“历史与主屏”或“备用屏”：前者包含冷热保留历史和底层主屏，后者只包含当前活跃备用屏的画面，不包含任何主屏历史。未启用备用屏时拒绝读取，不自动改查主屏。两种范围都只沿Alacritty真实WRAPLINE拼接，不跨硬换行；宽字符占位不作为文字，保留组合字符。不做Unicode规范化，不区分大小写时逐行Unicode小写比较。Enter／Shift+Enter前后查找，Ctrl/Cmd+F聚焦，Escape关闭恢复焦点，组合输入由IME处理。每次结果按命中的物理行段计数，跳到行段之外再查找，不枚举同一行段内的所有出现。已清理文本不包含；正则模式见补充说明，自然结束会话的只读查询见下节，TERM-09不计全量完成。

workspace_terminal_history_search复用当前WebView、nonce、原页owner和精确binding，查询前后复验且与capture共享锁。请求必须显式携带alternate布尔值，响应严格回显范围；缺少、错类型、未知字段及范围不匹配均拒绝。查询限512 UTF-8字节并拒绝控制字符，游标／十进制修订成对提交。每Actor批次含重叠读取最多2048行／512KiB；滚动窗口只保留不足一个查询长度的前缀或后缀，无匹配时把未决折行边界作为下一批起点，双向不跳过跨批次匹配。screenRows为1..256，主屏范围totalRows最多100000条历史加256条屏幕行；备用屏totalRows必须等于screenRows、coldRows为0且不得标记历史裁剪。匹配页仍限200行／128KiB，长匹配只显示末尾并明确提示，文本只通过textContent显示。历史分页RPC及默认严格解码不包含屏幕；搜索片段独立保存，禁用“更早／较新”，显式“最新历史”成功后返回主屏历史翻页，失败保留片段。范围切换清除旧游标并丢弃迟到结果。达到边界不绕回，不发送输入、不改选区或自动复制。

输出、清历史或resize使旧修订失效时停止，保留当前页并提示重新查找；busy／未知错误不重试，查询编辑、关闭或页面／会话变化丢弃迟到结果。本批直接检查为8项查找（含真实Actor修订）、3项既有分页、16项前端、类型／格式／产品构建及CLI＋SSH严格Clippy。Chrome模拟IPC核验跨历史／主屏的多行高亮、双向定位、文本安全、历史翻页隔离、返回历史、IME、720px布局、过期提示和Escape焦点恢复，只算组件开发检查。未跑全量或SSH／CLI矩阵，未计原生WebView、系统IME、性能或跨平台验收；标准Rust/Vitest及原生构建CI自动覆盖。日志见target/probes/primary-search-development/；前一批原页绑定隔离检查与记录保留在target/probes/history-search-development/。

## 有界正则查找

对话框增加“正则表达式”，可与区分大小写及两种查找范围组合。请求和响应必须显式包含regex布尔值，缺失、错类型、未知字段和模式回显错配都拒绝；切换模式重置游标并丢弃迟到结果。字面模式保持原有语义。正则采用已锁定的Rust regex非回溯引擎，不新增包版本；支持Unicode、字符类、分支、量词和锚点，不支持回溯引用或环视。512字节表达式上限，编译程序和DFA缓存各1MiB、嵌套深度64；无效或超复杂度表达式返回workspace.history_pattern，不向页面暴露表达式或引擎内部错误。

正则按完整逻辑行做is_match，沿真实软换行拼接，硬换行分隔；^/$锚点以保留文本的逻辑行边界为准，已裁剪的最早前缀不可恢复。每次定位整条命中逻辑行并高亮其物理行段，不枚举行内每次出现；零宽结果也按整条逻辑行前进。游标不得落在软换行中间。每批继续使用2048物理行／512KiB文本预算；未读完的逻辑行留待下一批，不能把批次边界当锚点。单逻辑行无法在预算内完整扫描则返回TooLarge，保留当前页并提示缩短输出或使用字面模式，不返回基于截断输入的结果。匹配片段仍最多200行／128KiB，长行段保留原有截取提示。

活动Actor、备用屏及EOF冻结来源共用同一算法和原页／窗口／binding校验；不授予输入或尺寸权限。直接检查为15项查找、2项原页／跨窗隔离、1项原生封闭参数和21项前端行为，以及TypeScript、Rust／Biome格式、Core／App／桌面库严格Clippy和产品构建，均通过。Rust语言服务请求超时，未计通过。直接检查和组件记录位于target/probes/regex-search-development/；使用现有Rust/Vitest及原生构建CI，不新增重型矩阵。组件Chrome采用模拟IPC，只验证控件、模式重置、错误提示、文本安全、布局和焦点，不计原生WebView、真实PTY／SSH、系统IME、性能或跨平台验收。

## Unicode 整词匹配

对话框增加“整词匹配”，可与区分大小写、正则及两种范围组合。请求与响应强制包含wholeWord布尔值；缺失、错类型、模式回显错配均拒绝，切换时清空游标并撤销旧操作的迟到结果。默认关闭，普通字面查找保持原有行为。

整词模式使用Unicode `\b(?:pattern)\b`，字面先由regex::escape转义，正则先将整个表达式分组，避免分支绕过边界。按Unicode单词与非单词转换判断，连续中文不自动分词，下划线、数字和组合标记也参与单词边界；不做Unicode规范化，大小写不敏感采用引擎的Unicode折叠。标点起止的查询同样遵循此边界定义。

整词与正则共用完整软换行逻辑行扫描、编译内存限制和2048物理行／512KiB文本预算。每次定位命中逻辑行，不跨硬换行；不足以扫描完整逻辑行时拒绝并保留当前内容，可关闭整词和正则后使用普通字面查找。主屏、备用屏、EOF快照及原页／窗口／binding授权继续复用原路径，不新增输入权限或会话资源。

直接检查19项查找、2项Registry隔离、1项原生协议、24项前端行为，以及TypeScript、Rust／Biome格式、Core／App／桌面库严格Clippy与产品构建均通过；匹配器Astrolabe诊断为Exact、零诊断。直接行为已覆盖Unicode／组合字符、字面转义、正则分支、大小写、软换行、备用屏、EOF双来源和原页隔离，组件Chrome仅验证控件、模式重置、错误状态、文本安全和布局，使用模拟IPC。现有Rust／Vitest及原生构建CI自动覆盖，不新增重型矩阵；原生WebView、真实PTY／SSH、系统IME、性能与跨平台仍待。开发记录位于target/probes/whole-word-development/。

## 自然结束后的只读查询

自然EOF在既有终态恢复捕获之后，另发布一份不可变文本快照。冷区转移所有权，不复制或落盘；热区、主屏及当时活跃备用屏的文本分配和行容器共用8MiB附加预算。备用屏未启用时不冻结其非活跃Grid；超预算返回TooLarge，不静默截断、不伪造空结果，来源不被部分移动；原有近期恢复快照及其预算不变。

SessionHandle在Actor退出后直接使用同一行投影、分页和软换行查找算法读取快照。EOF发生在命令入队和回复之间时，若命令因Actor退出而不可用，只读取已发布的快照，不再次入队。EOF使旧修订失效；冻结后修订稳定，支持主屏历史分页，以及主屏或明确选择备用屏的跨软换行查找。主屏与备用屏各自保持独立坐标，备用屏不进入历史分页，也不恢复输入权限。

快照仅在自然Ended终态发布，Closed或Failed不发布。它不持有Actor任务、驱动、PTY、SSH流或输入租约；会话最终释放后随handle一起释放。当前原页、窗口owner和binding generation仍在读取前后复验，刷新后必须重新绑定。界面仅将ready和ended视图开放给只读历史入口，暂停和失败状态不放行；不修改输入、尺寸或选择权限。

本轮检查覆盖EOF后完整冷热历史、UTF-8尾片段、主屏折行及备用屏隔离、旧游标拒绝、关闭/失败不发布、预算失败不改来源和原页/跨窗读取检查。直接前端检查17项通过；本轮仅检查相关Rust历史与EOF、Registry隔离、类型、格式和严格静态规则，不跑全量或新增重型矩阵，既有Rust/Vitest CI自动发现。日志见target/probes/ended-search-development/。真实PTY/SSH与原生WebView的结束后查找尚待验收。

## 备用屏查找补充
