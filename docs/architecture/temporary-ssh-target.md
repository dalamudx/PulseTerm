# 临时 SSH 目标来源

本批继续 VAULT-05 的“先临时连接，成功后可选保存”。来源、应用使用守卫、原页账本和成功保存接口已通过针对性检查。页面已接通临时选项、明确 MFA 选择和保存表单；Linux 固定 russh peer 的单条真实密码临时连接流程已通过，覆盖连接后暂不保存、明确保存、最近连接绑定、刷新与独立进程重开。两类来源和动态守卫均已检查，临时私钥真实认证与其他平台尚未验收。

`StateStore::temporary_ssh_target` 接受已验证的 `SshEndpoint`，后台发行 UUIDv7 和私有实例绑定的内存句柄，不写旧主机目录、机器图或 SSH Profile。句柄不可序列化或 Debug 输出，复制共享撤销状态，300 秒后失效；原页面回调撤销、异常及外来 store 实例一律拒绝。页面回调不得持有 SQL 读信用。UUID 用于显示和明确选择，不能独立授权连接。

密码与私钥临时来源复用原 SQLite worker 和操作级授权，分别捕获完整身份目录、Vault 密文／信封及 trust。在事务复核与首次指纹保存时重读同一个临时句柄和持久来源，拒绝撤销、身份或 Vault 变化。临时来源用单个虚拟 HostSnapshot 供原用户名／目标匹配，不把记录写入主机库。实际 peer 验证与身份使用批准保持独立。

两类 UsePreparation 的后续授权闭包加入临时来源存活检查。原页面、原 Vault epoch、原始选择及实际指纹继续由原批准链处理。准备通过不意味着后续一直有效，仍在 native 使用边界检查。CLI 的加载参数强制无临时目标，继续只接受保存 ID。
## 临时目标的交互认证

临时连接表单允许用户为已保存的账号元数据明确选择“交互认证 / MFA”，不自动选中或回退其他认证方法。`workspace_ssh_interactive_session_prepare` 从原页面账本解析临时 UUID，读取同一受监督的元数据来源；不接受额外地址参数，不读取保存密码。`SshInteractiveUsePreparation` 复核临时来源、账号用户名与原身份目录，其后授权守卫继续检查该句柄存活、原页面及 Vault epoch。准备前或准备后撤销都必须拒绝认证，不改写主机目录。

问答沿用原请求 token 和单次轮次，并在实际连接指纹核对后开始；回答不进入数据库或日志。成功沿用 Root 注册和原临时目标的 `mark_registered`，随后才呈现独立保存动作。“暂不保存”只撤销元数据句柄，已注册终端仍可恢复；CLI 继续只接受保存 ID。


Linux 生产 WebView 与受控真实 SSH 已通过六段临时 MFA 验收：取消、错误回答零回退、两轮认证、暂不保存、刷新不重认证、精确已有目标保存复用与四条连接退出。该实窗保存分支未覆盖新建主机；完整范围见[验证记录](../development/validation.md)，原始收据位于 `target/probes/workspace-temporary-interactive-result.json`。


## 原页账本与保存

`workspace_quick_target_prepare` 校验目标并由后台发行元数据和取消票据；`workspace_quick_target_cancel`、替换、换页和退出撤销旧句柄。单槽账本绑定原页面、WindowToken 和 reader。原指纹读取及密码、私钥与交互认证三类 Session prepare 根据原请求槽的目标 ID 解析账本，不接受页面追加启动地址、密码或指纹批准状态。发行回调保留原 reader／页面检查，不保留 SQL 读信用。

只有 Root 实际注册会话后，后台才标记该临时目标可保存。`workspace_quick_target_save` 只接受原票据和显示名称，从后台句柄取地址、端口和用户名。保存票据单次消费，并在 SQL 最终提交检查当前页面与取消状态；未知、过期、未注册、重复和已撤销目标拒绝，不自动重试。保存走原 Host CAS 事务，成功后才把新保存 ID 加入本机最近列表。临时虚拟 ID 不写 saved MRU。

前端“临时连接”先重核当前地址与预览，再打开原身份／指纹连接表单。取消和晚发行结果撤销句柄。原会话注册成功后显示“保存此连接”，可明确保存或“暂不保存”。取消保存只撤销元数据，不关闭已注册会话。表单先校验名称再消费票据；迟到或不确定结果不重复保存。

prepare 后撤销使 Intent native 守卫拒绝的反例在 `ssh-use` 下实际运行一项并通过，App ssh-use Clippy 通过。首个命令选择零测试不计通过。原页账本替换／取消／换页／未注册保存拒绝单项及 workspace-ssh＋workspace-cli Clippy 通过；Rust LSP 为 Exact 且无诊断。临时 IPC 三项和保存表单两项反例及22项受影响组件检查通过。新增三项交接反例、类型与 Python 检查通过。`mise run probe-workspace-temporary-ssh` 已通过：原连接表单取消零认证／零写；两次明确密码认证及终端就绪；首次暂不保存保留会话且不写主机／recent；第二次 Root 注册成功后一次修订保存未保存目标，并把真实保存 ID 记入最近列表；原记录及凭据／trust／组织不变，刷新与独立重开、两次正常退场通过。已有精确目标复用不会制造重复项或推进主机修订；该分支已单独保留日志。密码遮罩读取和夹具复用导致的探针失败也保留，修正后未改变产品授权。证据归档见 `target/probes/temporary-ssh-acceptance.json`，34 份文件 SHA 核验通过；全部原生进程退出后 `clean-dev` 清理 14.9 GiB，任务临时目录确认为空。
