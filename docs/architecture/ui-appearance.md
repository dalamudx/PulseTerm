# 界面外观设置

工作区“设置”提供浅色、深色和跟随系统三种界面外观，以及青、蓝、绿、琥珀、红五种固定强调色，分别显示内置默认或用户覆盖来源。内置默认保持浅色和青色。终端字体、14px 默认值和终端 ANSI 调色板保持独立配置；界面设置不发送终端输入或获得会话主题应用权限。

## 保存与显示

```toml
[ui]
appearance = "system" # "light" / "dark" / "system"
accent = "cyan" # "cyan" / "blue" / "green" / "amber" / "red"
```

外观与强调色分别存入后端固定私有目录内的 `settings.toml`，沿用原页单次快照、CAS、实际 I/O 额度及退出监督。单次只更新所选字段，保留另一个界面字段、终端设置和已有注释。恢复继承只移除该字段覆盖，分别回到内置浅色或青色。两项只允许用户级设置；主机或分组解析、编辑及整表替换均拒绝非空的 `[ui]` 覆盖。

选择框只改变表单内的局部预览。保存获得当前页成功回执后才更新本窗口界面；取消、失败、旧表单和关闭后的迟到回执不能应用草稿。保存失败要求重新读取，不能拿旧票据重试。显式打开／重新读取设置会采用读到的有效外观。其他窗口保持自身已显示设置，直到显式重新读取或页面重载；没有新增跨窗口自动热更新或文件 watcher。

跟随系统使用当前 WebView 的 `prefers-color-scheme`。显式浅／深色不跟随系统变化，监听随页面或预览释放。无法查询系统偏好时保留当前已显示外观，并允许用户改选浅／深色；不把查询失败当作成功切换。

## 协议与绘制

界面外观在 v4 投影中新增 `ui_appearance`，v12 新增 `ui_accent`；当前生产设置投影为 v14，前端继续严格接收 v1–v13，旧投影缺少强调色时采用内置青色。v12 必须提供固定枚举强调色，且只能带 default/user 来源；缺字段、未知值或其他来源均拒绝，不接收 CSS、URL、自定义色值或主机／分组的界面来源。

界面使用已锁定 Radix Slate 中性色与 Cyan／Blue／Green／Amber／Red 浅深色 CSS，包含原生控件 `color-scheme`。外观切换固定类名，强调色切换固定 `data-ui-accent`；草稿预览仅在表单局部设置该属性。正文预览和带色背景上的文字使用第 12 阶色值，焦点／边框使用第 11 阶；选中项底色使用第 4 阶。不新增动态样式或放宽 CSP。终端固定预设及 ANSI 查询共用后端基色，见[配色预设](terminal-color-presets.md)；按 Profile／主机选择、在线主题应用、自定义主题和导入库仍待。
