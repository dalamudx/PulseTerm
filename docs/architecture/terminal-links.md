# 终端链接识别、检查与系统浏览器交接

TERM-10／SEC-08 已接通链接识别、目标检查、显式复制和 Linux 受限系统打开。Windows／macOS、真实系统浏览器与原生 WebView 验收仍未完成，不能据此关闭完整链接安全验收。

- 普通 HTTP／HTTPS 文本通过 xterm 公共 `registerLinkProvider` 与 buffer 单元格识别；OSC 8 通过显式 `linkHandler` 进入同一检查窗口，首次创建时即替换默认打开行为。
- 严格 IPv4:端口与 `[IPv6]:端口`（可带路径、查询和片段）也通过同一 provider 识别，转换为完整 `http://` 候选后才进入检查窗口。界面明确提示按 HTTP 网页地址解释，端口不证明服务支持 HTTP；不推断 HTTPS、SSH 或其他协议，不支持主机名端口、IPv4 缩写、前导零、IPv6 zone ID 或无方括号 IPv6。端口范围 1～65535，拒绝前导零。
- 拒绝从其他协议、账号或地址标记内部截取 IP 片段。原有单元格坐标、候选与字节预算及旧视图撤销检查继续适用；OSC 8 目标仍必须显式使用 HTTP／HTTPS，不对其缺失协议作推断。
- 绝对文件路径通过同一文字 provider 识别，支持 Unix 路径、Windows 盘符路径和正整数 `:行[:列]`（不超过 2147483647）。无引号路径不接受空白；完整的单／双引号路径可包含普通空格，行列后缀可在包围引号内或外。路径使用独立来源标记进入只读检查，显示完整字面路径与单独的行列信息，显式复制只复制去除包围引号后的路径。文件目标没有浏览器打开按钮，也不调用原生命令、读取文件或推断其属于本机。
- 文件路径不做 URL 解码、本地规范化、变量展开或 Shell 转义。引号外的行列后缀优先；没有外部后缀时，按原规则解析路径尾部的数字后缀。保留文件名标点和 Windows 反斜线，仅移除明确的包围符。拒绝相对路径、`~`、UNC／网络路径、`.`／`..` 分量、未完整包围的带空格路径、嵌套或未闭合引号、控制符／非普通空白／双向格式字符及超限内容。不从其他 URI 或账号内部截取路径。OSC 8 仍只按网页目标策略处理，不把其 `file://` 或缺失协议目标降级为文件操作。外部编辑器打开尚未实现。
- 普通文本按软换行逻辑行读取，单次最多 8 个物理行、16384 个 UTF-16 单元、每行 4096 个单元格，最多考察 32 个候选。超限不返回截断地址；宽字符、组合字符和跨行范围按单元格定位。
- 前后端分别检查不含凭据的 HTTP／HTTPS 绝对地址，原始及规范化地址均最多 4096 UTF-8 字节。拒绝空白、反斜线、控制符及双向显示控制符；原生目标对象拒绝未知字段。
- 检查窗口通过文本／只读文本框显示规范化完整目标、协议和 ASCII 主机名（国际化域名为 punycode），不使用 OSC 8 的显示文字替代目标。无效目标不显示地址框，也不能复制或打开。
- 只有有效视图中的可信激活才显示窗口；复制和系统打开分别需要可信按钮点击。自动聚焦地址框，重复打开合并；失败可重试或复制，已成功交接后当前确认窗口不重复提交。平台不可用时保留复制入口。
- 连接创建时冻结原页 nonce，只有完成呈现且仍有效的视图才能请求系统打开；自然 EOF 的只读视图也可用，不借用输入授权。切换或释放视图移除窗口，迟到结果不能更新旧界面或恢复旧焦点；IME 候选态 Escape 让路。

## 原生系统交接

`workspace_terminal_link_open` 通过实际 Invoke WebView 的窗口状态取得 owner，验证本地工作区来源和当前页面 nonce。地址在原生再次解析，不能传程序、参数、文件地址或任意协议。

Linux 使用已锁定 GTK／GIO 的默认 URI 异步接口，不拼接命令行或新增通用 opener 插件。原页检查在命令接收和主线程交接前各执行一次；排队超过 3 秒、窗口关闭、页面撤销或等待方取消时不开始交接。主线程调度错误明确返回失败。非 Linux 返回平台不可用。

每窗口最多一个未完成打开任务。信用随原生回调存活，等待方取消不能提前释放；窗口关闭及应用退出等待实际回调完成。确认后已经提交给系统的动作不能撤回，视图撤销只阻止后续请求及旧结果发布。完成收据仅表示 GIO 接受分发，不证明浏览器窗口出现、页面加载、网络成功或浏览器退出；应用也不等待浏览器进程结束。

该动作只离开终端交给系统浏览器；不会导航 WebView、发送终端输入或重建输出订阅。只注册受限的 Tauri 命令，工作区 CSP 保持现有严格策略，不新增通用系统启动权限。

## 开发验证

本批 3 项原生直接检查覆盖目标策略／封闭参数、等待方取消后的容量与退出等待、原页导航／跨窗／远程来源拒绝。63 项受影响前端行为以首次批次和失败项定向续跑合并计数，覆盖回调透传、原始 nonce、呈现前拒绝、自然 EOF、退场拒绝及规范化字节预算；TypeScript、局部 Biome、Rust 格式、桌面库严格 Clippy 和产品构建通过。不跑全量回归或 SSH 认证矩阵。

真实 Chrome／xterm 组件检查覆盖普通文本与 OSC 8、显式打开、重复抑制、失败重试、不支持时复制、无效目标、独立窗格、IME／关闭焦点及进行中撤销。系统打开与剪贴板适配受控，外部请求被拦截，确认零导航与零终端输入；不是 GIO 实际启动浏览器、系统剪贴板、原生 WebView、PTY／SSH 或跨平台验收。

本批记录在 `target/probes/link-open-development/`；之前链接识别的 24 项前端检查、日志和截图保留在 `target/probes/terminal-links-development/`。
