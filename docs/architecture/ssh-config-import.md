# ssh_config 的只读元数据边界

`pulse-ssh::config` 接收显式文本和查询参数，返回主机、端口、用户名及身份文件提示。它不读取私钥、不查询 Agent、不执行命令、不解析 DNS，也不授予连接或导入写入权限。产品的 SSH-05／VAULT-09 仍需要目录读取、源变更处理及原页面导入确认。

## 文本解析

`ConfigBundle::parse` 解析一个主文本和至多 32 个命名的 Include 文本；这些名称是匹配键，不是文件访问许可。每源上限 256 KiB，全部源 512 KiB、4096 行，每行 8192 字节；词长 1024 字节、每条至多 32 个词。UTF-8、控制字符、非法引用和字段不符合边界时返回固定错误，不包含输入、文件名或命令内容。

支持 Host 通配与否定、HostName、User、Port、IdentityFile、IdentitiesOnly、Include，以及 Match 的 all／host／originalhost／user／localuser 条件。Host 按原始别名区分大小写；Match 主机条件不区分大小写，用户名条件区分大小写。词法支持等号、单双引号、受限转义和词边界上的注释；词中 `#` 不被删去。显式查询中的用户和端口覆盖文件值，标量采用先取得的值；IdentityFile 按顺序去重，保留 `none`、波浪号和 token 为原始提示，不展开或读取。

HostName 仅支持 `%h` 和 `%%`。Include 按提供源名称的词法顺序匹配，通配不能跨目录或隐式匹配隐藏文件。每个被包含文本处理完恢复外层 Host／Match 条件上下文；取得的配置值继续保留。活动 Include 缺源明确失败，与 OpenSSH 忽略未匹配文件的行为不同：调用方不能把读取失败映射为空源。递归深度 8，重复展开总计至多 4096 条指令，所有通配匹配共用一百万步预算，循环明确拒绝。

活动的未支持选项，包括 ProxyCommand、ProxyJump、LocalCommand、RemoteCommand、转发和安全策略修改，均返回 Unsupported；未支持的 Match 条件（包括 exec、final 和 canonical）同样拒绝，绝不运行外部命令。未匹配 Host 块里的普通未支持选项不生效。此限制不改变 ADR-028 的未来受控 Route／系统 OpenSSH 设计。

## Unix 固定主文件

`load_primary_config_directory` 只读可信后端选定目录中的固定 `config`。路径必须绝对，逐组件以目录描述符和 NOFOLLOW 打开，最终目录要求当前所有者、无组／其他用户权限且具备所有者读／遍历权限。文件必须当前用户所有、普通文件、单硬链接、具有所有者读权限、无组／其他用户写权限，且不超过主源字节上限。

使用只读、非阻塞、CLOEXEC 打开；拒绝叶链接、父链链接、FIFO、目录和超长文件。读取后核对描述符的设备、inode、长度和 mtime／ctime，重新打开原路径核对目录与当前文件身份。缺失、权限不足、异常读取和非 Unix 平台返回 SourceUnavailable，不创建文件、不修改已有权限，也不把错误转换为空配置。已存在的合法空文件可以成功解析。

固定主文件入口仍只接受显式 Include 文本，磁盘同名文件不会被自动读取。新增 Unix `ConfigDirectoryReader` 接收后端选定的私有目录和最多 32 个已获准相对文件名；文件名预算、层数、重复项、绝对路径／父目录逃逸和模式字符在 I/O 前验证。目录逐级 NOFOLLOW 且属当前用户、私有并可读可搜索；文件沿用单硬链接、非阻塞、只读与 256 KiB 单源／512 KiB 总量限制。此集合是显式授权目录，不是自动通配发现或任意前端路径入口。

`capture` 保留固定主文件与批准集合的完整字节、文件状态和经过的目录状态；返回前用同一读取器再次检查。`confirm` 首先检查原读取器实例，随后重读所有源并复核字节、设备／inode／长度／mtime／ctime 及目录状态和有界真实成员集合；外部更改、替换、删除、新成员和根目录替换导致拒绝。新读取器不能确认旧快照；被替换的根需要显式新建读取器。快照不实现 Debug／序列化／Clone，`resolve` 只返回明确的已捕获元数据，不能代替源确认。

同步读取层已通过完整基础回归、862 项前端、组合原生消费方 strict 和 bindings；最终 exit 5 只来自 8 项许可与 2 项维护审计阻断。确认仅是有限次读后比较，不提供完整 TOCTOU、跨文件原子快照或后续持续新鲜性保证，更不授予身份、密钥或连接权限。目录时间戳曾漏掉新成员，已改用独立目录描述符枚举并比较真实成员集合，总预算 4096 项／512 KiB 名称字节。九组真实集合反例、公开探针 29 项、SSH 全特性 54 项与 4 项文档测试、strict／Exact 已通过，原失败证据保留。

## 原页面独立保存导入

预览／核对票据不能直接提交保存。用户明确“准备保存”后，后端消费原读取票据，确认原源与查询，读取同一私有存储的主机快照，再确认源，生成独立一次性导入票据。地址、端口、用户名和名称固定在后端；页面保存时仅提交票据。User 保存为主机用户名提示，IdentityFile 只显示数量，不保存路径、读取密钥或选择 Vault 身份。

保存与取消共用单槽：queued 取消可退出，执行中的 slot 和共享 I/O 信用保持到原生 SQL 操作退出。旧页面、过期／重复／跨实例票据、源成员／内容改变和数据库快照变化均拒绝；SQL 事务的授权检查包括原页和全源重验，最后检查失效会回滚已写入的主机。文件系统与 SQLite 没有共同事务，其他进程仍可能在最后源检查后修改配置，本实现不声称跨二者的原子 CAS 或完整 TOCTOU 防护。

八组真实数据库反例、默认／SSH strict、211 项其余 Native（4 忽略不计验收）以及 68 项前端预览／导入协议／表单反例、tsc 已过。Rust 导入模块 Exact 无诊断；TypeScript LSP Unknown 不计通过。Linux 独立私目录和双进程实窗通过：准备后取消和外部源变更均零写入，重新准备只新增一条主机，同 ID 经过刷新和进程重开；其他九表摘要不变、零终端启动，两次正常退出。准备／保存／关闭在 640px 高度完全可见；限定 PID 的 AT-SPI 可见文案与目标输入焦点核对后截屏。完整 check/test/probe、930 项前端、bindings、新保存与只读预览公开任务及主机编辑兼容均通过；最终审计仍为 8 许可／2 维护阻断。实时变化检查正在接入，平台验收与未支持配置项仍待实施。

## 可见预览的源状态检查（Linux 完整验收通过）

源状态命令借阅原预览票据，保留原页面作用域和五分钟期限，不消费保存票据、延长授权或重新选择目标。状态读取前后均核对同一票据，已消费、替换、过期或导航后的迟到结果拒绝发布。检查复用共享原生 I/O 信用，等候取消不能提前释放正在阻塞确认的信用，退出屏障仍等待实际读取退出。

对话框仅在打开且页面可见时每两秒串行检查；前次退出后才调度下一次，原票据不会更新。检查中禁用显式确认和准备保存；关闭、换别名、新预览、显式确认和准备保存停止检查。源变化只保留最后绘制值并撤销旧来源的准备入口，不自动重读、覆盖字段或选择身份。共享额度暂忙可稍后检查，不确定失败停止检查并要求重新预览，保存不会自动重试。



## Windows 来源与共享确认算法

显式 `workspace-ssh` 的 Windows 预览、来源状态、确认和 Host 元数据导入复用同一条原页面与 SQL CAS 链。`pulse-ssh::config` 的同步 `ConfigSourceFilesystem`／`ConfigSourceDirectory` 由受信任 Rust 适配提供，页面仍只传别名；这些接口和文件戳不授予文件、凭据或连接权限。Unix 保留逐组件 NOFOLLOW、当前所有者、权限和单硬链接检查。旧 `load_primary_config_directory` 辅助函数仍仅支持 Unix，不用空配置模拟其他平台成功。

Windows 原生适配位于 desktop，底层 `ReadOnlyDirectory` 复用现有私有目录和文件租约：目录及祖先按句柄／路径身份、当前账户、ACL 和 reparse 属性复核；主文件与选中的 Include 必须为可准入的单链接普通文件。只枚举目录名字，不查询或读取 IdentityFile 提示。文件读前后校验身份、长度和变更时点；确认继续前后检查目录戳、完整成员集合及所有原源的字节。读取不会创建目录／文件、修复现有 ACL 或改所有者，不声称跨文件系统／SQLite 原子快照或完整 TOCTOU 防护。

默认来源仍为后端选择的用户 `.ssh/config`，既有验证目录变量属于进程配置，不接受页面路径。Include 仅支持共享子集中的相对 ASCII 路径及 `/` 分隔；ADS、驱动／绝对路径、父级遍历、DOS 保留名、尾随点和不安全链接均拒绝。Windows 名字枚举不能无损表示为 UTF-8 时明确失败；不读取 ProgramData 系统配置。每源 256KiB、总源 512KiB／32 个 Include、目录成员总计4096／名字512KiB等原限额继续有效，活动的未支持选项明确拒绝，不降级为直接连接。Windows 的本地用户提示读取 `USERNAME`，不承诺域账户／系统 OpenSSH 名称映射兼容，后续须在真实环境验证。

读者只保留原目录身份，原生目录／文件租约随受监督阻塞操作结束；页面取消不能提前释放 I/O 信用。快照继续绑定原读者和原查询，预览不是保存权限，保存仅创建 Host 元数据；不保存身份路径、不挑选 Agent 或 Vault 身份，也不触发连接。

原生组件入口为 `mise run test-windows-ssh-config`，通过 `xtask/windows-config-probe` 引用与生产同一份适配，逐项核对4个源码测试名及单一摘要。覆盖惰性 Include／提示不读取、外读者／查询、改写／新增成员、同字节文件与目录替换、ADS／DOS／越界／硬链接及预算拒绝。16项执行器反例覆盖零／部分／错名／重复／忽略／失败／超时与未知状态；Linux 运行这些反例不算 Windows 执行。四个原生夹具已严格交叉检查，Windows 普通用户 GUI 预览／状态／保存、刷新／取消与物理退出仍待原生验收。当前批次结果及清理记录将保存到 `target/probes/windows-ssh-config/verification-v1.json`。
