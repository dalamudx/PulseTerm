# 工作区设置导航

工作区“设置”弹窗按外观与配色、字体与排版、历史与滚动、键盘与剪贴板组织已接通的设置。分类为原生选择框，搜索支持产品标签、固定配置键和常用中英文名称，多词按交集匹配。当前投影中的字段才会出现；未来新增投影字段须在类型完整的分类目录中明确归属。

导航仅处理本地显示，不读配置、不写文件、不新增 IPC 或执行能力。分类和搜索词只在本次弹窗打开期间保留，完成或 Esc 关闭设置后清空；进入快捷键时仅挂起并保留，返回后继续使用；不会持久化到用户设置。远端终端文字、用户凭据和用户配置内容不参与搜索索引。搜索内容不作为 HTML 插入。

## 保存与撤销

`WorkspaceSettingsEditor` 保留原有 read／save 适配器、原页面 nonce、一次性设置票据、单字段 Set／Remove 及后端源冲突检查。每次成功保存仍采用后端返回的完整投影重建字段控制器和来源显示；支持 AbortSignal 的渲染监听被撤销，所有旧表单回调还须通过原 epoch／投影身份重检，不能再次保存。

保存期间禁用字段及导航；成功后保留分类与搜索条件，并恢复发起操作的控件焦点。用户已移到完成按钮等其他控件时不夺回焦点。关闭／页面撤销会使迟到结果失效，不重新打开弹窗；重新打开必须重新读取。写入结果不确定时清空字段并禁用导航，保留原“不自动重试”提示，通过重新打开读取后端实际状态。

## 快捷键入口与返回

“编辑快捷键”作为本地目录条目加入键盘与剪贴板分类，可用快捷键、键位、keymap、keybindings、shortcuts 等关键词检索。只在提供键位入口的产品设置页出现，不伪造为后端字段或增加设置投影字段；搜索和切换分类不写任一配置。

进入快捷键前，仅在设置读取完成且无活动保存时挂起设置弹窗，保留原 DOM、未保存草稿、筛选与滚动位置。快捷键继续独立读取／确认来源、取得写入同意、保存和恢复内置。点击返回或 Esc 关闭快捷键后，通过生产 `settingsKeymapLink` 返回原设置控件；不重新加载或安装默认设置，不消耗、续期或转移任一来源票据。后续设置保存仍须通过原票据和源 CAS；过期／冲突维持既有失败后重开读取规则。

旧返回回调绑定挂起时的 epoch 和页面 nonce，关闭设置、换页、销毁或新一次打开后不得复活旧表单。已有其他模态时拒绝叠加，也不解除其忙状态。快捷键的失败重读、关闭后的迟到响应继续由其原控制器隔离；关闭整个设置后再次打开必须重新读取。

## 键盘与布局

打开并完成读取后，焦点进入带标签的搜索框。分类使用标准 Tab／方向键操作；清除筛选后焦点回到搜索框。各分组使用有名称的 section 和标题；隐藏字段及空分组离开显示与键盘顺序，结果数量／空结果通过 polite status 提示。弹窗的 Escape 仍交给已有窗口级手势隔离，不增加搜索层 Escape 或终端输入处理。

桌面使用横向筛选栏，窄窗口将搜索独占一行并允许字段标签换行。弹窗内仅字段区滚动，导航和完成操作保留在可见区域；沿用已有浅／深主题色及可见焦点。默认终端字号仍是 14px，预览、保存及会话应用时机维持原规则。

## 开发检查与范围

针对设置编辑器／设置协议／外观执行既有直接行为检查和 TypeScript，构建真实工作区页面；用受控 read／save 适配器在 Chrome 检查筛选零写入、保存／恢复／焦点、旧 DOM、迟到响应、失败重读及窄窗口布局。轻量收据在 `target/probes/settings-navigation-development/`。沿用现有前端 CI，无新增全量或 SSH 矩阵。

这些是组件和构建证据，不证明原生 WebView、辅助技术或三平台验收。语言字段复用真实设置持久化与来源授权，当前工作区／设置／快捷键双语范围见[工作区语言](workspace-language.md)；UI-05 完整弹窗及错误文案、其他设置整合继续按当前清单推进。内置主题和作用域开发链路已接通，集中实用链仍待验收；UI-02 专指窗口材质。
