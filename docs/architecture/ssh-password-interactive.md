# 保存直连密码与 MFA 联合认证

本批范围为GUI明确选择的保存目标直连，Linux原生链已通过。临时目标、CLI和逐跳方法选择继续按后续工作包接入。

## 授权与期限

`PasswordInteractiveSessionGesture` 在原点击捕获页面、Host/Identity、可用 Vault 代际和固定 300 秒截止时间；批准不能借用后续解锁。动作和意图不能由普通密码请求、只读来源或认证布尔回执转换。准备只接受保存直连来源；路由、临时来源、陈旧快照及取消均拒绝。普通密码准备仍为 5 秒。

`workspace_ssh_password_interactive_session_begin` 是独立命令，复用现有问答 Channel、原请求令牌和一次性轮次。密码来源准备、终端启动、取消及回答沿现有监督入口处理。界面仅在保存直连中提供“密码 + MFA”；方法不可用或失败时不改用其他认证方法。

## 两因子与明文生命周期

可信 `PasswordInteractiveSessionSink` 的第一阶段只接受实际密码部分成功，且服务端下一步必须包含 keyboard-interactive。密码单因素完整成功、拒绝以及其他后续方法都不能建立联合会话。

第一阶段返回后，原密码借用在既有监督任务中结束并清理。问答在 `prepare_authenticated_terminal` 中执行，适配器只保留用户名，不保存密码。每轮沿用有界 Broker，并在开始、显示／回答边界重新校验原密码来源、页、代际、截止时间及实际 peer。MFA 完成后才准备 PTY，经原来源复核和统一 `AuthenticatedProtocolParts::commit` 注册会话及冻结行为设置。

取消、页变更、锁定、超时、错误回答或来源变化均进入原物理排空链；不把取消确认当作原生退出，不提前释放容量。密码和问答值不进入日志、页面返回值或持久化配置。
