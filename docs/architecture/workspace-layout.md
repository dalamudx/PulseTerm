# 工作区布局与窗口偏好

`WorkspaceSplit` 将已有根会话映射为有界布局树，最多八个窗格。左右／上下分屏作用于焦点叶；选择直接相邻的已有叶时仅切换该分屏方向，同一会话不在多个窗格重复显示。每叶持有独立 `WorkspacePane`／ViewHost／fit，改变布局复用节点与控制器。隐藏或改变布局不是关闭会话。

分隔条接受主指针、方向键和 Home／End。指针移动只用当前页 nonce 样式预览分隔条，松开才提交一次 20–80% 比例；Escape、pointercancel、捕获丢失、布局重绘或页面退休取消预览。侧栏滑块提供无拖动的单指针替代。比例作用于焦点所在的直接分屏，最大化和调整在途禁比例。

最大化保留其他叶与连接，放入 hidden/inert 容器；隐藏叶不能成为 DOM 输入焦点。还原重新使用同一节点和已有连接。刷新时隐藏叶只建立控制器，延迟到首次显示后才attach，避免零尺寸捕获；最大化的就绪状态只看当前可见叶，仍可还原等待显示的叶。切换至隐藏叶时先还原；“仅显示焦点”会退休其他显示连接，保留后台根会话。当前最大化隐藏叶仍消费其已连接的输出，不计作 TERM-06 后台零开销实现。

布局／焦点／最大化偏好保存在当前窗口 `sessionStorage`，不跨进程／窗口持久化。读取预算 32 KiB、版本固定，拒绝重复会话、非规范叶身份和坏比例；恢复时与后端返回的当前会话目录核对，裁掉不存在的叶并收缩单子节点。配置损坏或存储不可用不启动替代终端。明确关闭先按原确认路径回收被选根，再对剩余布局恢复。此偏好不是绑定、输入或启动授权。

所有尺寸改变沿用 [终端布局授权](terminal-layout-authorization.md) 的当前页／代际、原生尺寸确认、旧输入撤销和重新捕获；不重复 enable 输入、不绕过 Commit ACK，也不自动重试未知原生失败。任一当前可见叶 Ended／failed／loading／resizing 时拒绝新的比例、嵌套或最大化；自然 EOF 的较小网格重排仍待实现。
CLI `split`／`split-pane` 候选衔接复用原页面确认、后端 Profile 身份和 startup ticket。已有嵌套时捕获不可变布局树与焦点会话，比例／方向／最大化改变都会使旧捕获失效；最大化、显示调整在途和八窗格不批准新增。批准后的新根会话加入焦点叶，其他叶不换连接。`probe-workspace-nested-cli` 只测取消零启动、批准一次嵌套、原PID／网格保留、输入隔离、最大化拒绝和退出，Linux 短实窗已通过，收据 `workspace-nested-cli-acceptance.json`；首次夹具默认焦点误选的证据保留，先核对原生输入归属后复验通过。


公开 `mise run probe-workspace-nested` 和 Linux CI 使用三条后端发现的 PTY，一条真实 WebView 路径覆盖嵌套尺寸、松开才调整、取消、键盘、最大化输入隔离、刷新同 PID、关闭焦点后的剪枝和原生退出。28 项布局／控制器／偏好测试与新增两项隐藏首次捕获反例通过，UI 类型检查及真实三PTY实窗通过；首轮按钮定位和最大化刷新零尺寸捕获失败证据保留。TS LSP 为 Unknown，不计诊断通过。未重跑与该纯前端变更无关的 Rust 完整回归或在线审计；连续拖动性能、IME、DPI、三平台和发布门禁仍保持原限制。
