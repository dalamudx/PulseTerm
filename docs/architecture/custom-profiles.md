# 自定义本地 Profile

## 产品使用链

本地 Profile 管理提供独立自定义目录，可创建、复制、编辑、显示／隐藏、删除与明确恢复。名称和绝对程序路径由用户显式保存；有序字面参数、空参数、工作目录、环境覆盖／移除与稀疏外观行为复用现有 [Profile 编辑器](./profile-editor.md)。参数不经 Shell 展开，保存不启动，读取、刷新和重新打开不自动启动。

每个项目使用后端分配的规范 UUID v7，和自动 Shell 身份分开。新建或复制产生新身份；删除保留原配置、身份及同步墓碑，恢复复用原身份。隐藏只影响目录可见性，不终止已有会话。名称、路径、参数和环境值始终作为字面文本，语言切换不保存、删除或启动。配置是明文设置，不能用作凭据存储。

## 存储与编辑授权

`pulse-store::custom_profiles` 复用私有 SQLite 的共享 worker 与 `app_state`，保存有界、版本化目录，不新增数据库表。目录最多 64 项，每个项目复用原配置预算，目录序列化预算 512 KiB。记录保留 UUID、创建／修改时间、HLC 及删除墓碑，为后续同步保留字段；本批不实现同步传输。

读取快照绑定原 StateStore；保存执行完整来源比较、事务与提交授权 gate。跨实例、旧快照、修改后改回、删除恢复、取消、损坏记录及耗尽版本都不能覆盖为默认。相对程序路径、NUL、保留环境名或超出原预算的配置拒绝；启动失败不会选择其他程序。

`workspace_custom_profile_read/save/cancel` 使用独立一次性票据，绑定原注册表、原页、原目录、目录快照和 60 秒期限，复用 ProfileReader 的 I/O 容量和退出屏障。前端保存等待有界，关闭／导航退休旧控件和票据；失败或不确定结果须显式重读，不自动重试。只读侧栏目录不创建、刷新或延长编辑票据。

## 默认选择、CLI 与启动

[默认 Profile](./default-profile.md) 同时支持自动 Shell 与保存 UUID，保留旧配置和投影。默认事务同时比较自定义目录；隐藏／删除的默认 UUID 保留但不可启动，不回退。保存选择不启动，显式启动前重新核对实际选择，变化时要求再次点击。

`workspace_custom_profile_open` 只接收保存 UUID。后端经原窗口的监督存储路径重读当前配置，冻结历史／配色与 Profile 外观，然后复用原页启动 scope、native 线程、Root 收养、取消和退出屏障；前端不能在启动请求覆盖程序、参数、目录或环境。已有会话保留原启动配置。

CLI 目录仍是有界身份列表，包含可见自动身份与保存 UUID，不投影程序或环境。普通／分屏／冷启动审批接受规范保存 UUID，继续要求原窗口明确确认。Capability 只允许已知自动身份或规范 UUID，不接受路径、非规范 UUID 或任意命令参数；确认后重读保存配置，取消不能授予启动权限，已收养会话不因回执丢失自动重试。

## 验证边界

真实文件重开、目录 CAS、删除恢复身份／HLC、提交前撤销及默认事务已有直接检查；真实 PTY 核对字面参数、环境、工作目录、启动配色以及删除／旧页面拒绝。23 项 Chrome 组件检查覆盖创建、保存重开、复制独立身份、编辑／隐藏／删除恢复、失败显式重读、默认不可用、双语、390px 布局，以及侧栏刷新未完成时编辑目录不并发读取；I/O 为模拟依赖。Store／App 严格 Clippy、桌面库 CLI＋SSH 产品组合严格检查，以及原生 GUI／CLI 编译通过。Linux WebView 实窗通过保存零启动、明确 GUI 打开、独立进程重开保留 UUID 且零启动、CLI 目录不投影执行参数、原窗口批准后启动、刷新不重复启动和两次 native 退出回收。验证修复了 UUID／十进制会话 ID 混用及保存后侧栏／编辑目录争用单 I/O 槽。证据见 `target/probes/workspace-custom-profile-result.json`；不代表三平台或系统 IME 验收。

当前生产自定义程序路径限 Unix。Linux 证据不代表 macOS 启动文件、Windows Shell／WSL／ACL、系统 IME 或跨平台验收；SSH 凭据和连接权限保持独立。
