# 工作区界面语言

当前生产工作区支持用户层 `ui.language = 'zh-CN' | 'en'`，默认简体中文。设置页“外观与配色”选择语言后显式保存，保存成功立即应用到当前工作区；关闭、失败或取消草稿不切换。重开设置和新窗口读取实际保存值，恢复继承移除用户覆盖并回到简体中文。没有语言配置时保持旧版本行为。

## 配置与页面权限

`UiLanguage` 是闭合枚举，仅允许用户设置；分组／主机配置拒绝语言字段，避免改变全局界面。Set／Remove 复用原页面 nonce、一次性票据、源 CAS 和监督文件 I/O；写入不确定时不自动重试，必须重开读取。支持标准 `[ui]`、内联表和点键形式，保留相邻字段与注释。

设置投影 v15 在 v14 基础上新增带来源的 `ui_language`；v1～14 保持旧闭合形状，不能混入新字段。前端严格校验语言与来源，不能从配置加载翻译文件、URL、脚本或任意路径。

## 显式文案绑定

`workspace-language.ts` 与 `i18n/settings.en.ts`、`i18n/workspace.en.ts`、`i18n/ssh.en.ts`、`i18n/identity.en.ts`、`i18n/profile-organization.en.ts`、`i18n/connection.en.ts` 提供原文／英文目录和占位符消息。静态工作区框架与已接入的 SSH、身份、Vault、Profile、组织、指纹、导入与快速连接弹窗在用户名称与终端挂载前注册已知文字、ARIA、标题和占位提示。动态组件显式调用文字／属性绑定，切换时更新原文字节点及属性，不替换控件、整页重载或重建终端。

占位符参数默认视为字面用户数据，只有显式嵌套的应用消息才再翻译。远端输出、Shell 字节、Host／Profile／Identity 名称、用户输入、文件内容和凭据不进入翻译目录。文本始终通过文本节点和属性赋值，禁止插入 HTML。语言自称与字体多语种字形样本保持原文。

`document.documentElement.lang` 随应用语言同步。页面撤销后不能再切换；绑定使用弱引用，重建时移除已断开的旧节点。语言保存重建表单后恢复其他字段草稿、配色预览、筛选、滚动与焦点；用户已主动移动焦点时不抢回。设置读回同样应用当前后端语言，覆盖失败重读及其他窗口保存后重新打开的情况。

## 当前范围与搜索

已接通工作区框架与状态、完整设置字段／来源／说明／预览、快捷键来源确认与写入同意、命令面板，以及 SSH 主机／多入口管理、SSH 配置、连接选择与跳板逐跳确认。共享目录搜索、批量删除数量与后果提示使用显式消息；用户名称、地址、端口、用户名、实际算法和指纹作为字面参数保留。切换保留输入草稿、选择与焦点，不提交表单、不启用不可用身份、不批准连接；逐跳待确认状态使用同一消息更新可见状态与辅助目标摘要，Esc 仍明确拒绝。设置和命令保留中英文检索，操作继续依赖既有独立授权。粘贴通知使用原文消息标识比较，切换语言不影响通知清除行为。

密码身份、私钥身份及导入、Agent 身份与 Vault 创建／解锁／锁定已接入；共享身份弹窗的模式标题和说明随入口显式绑定。敏感输入保持原控件与值，切换不提交、不发现 Agent 公钥、不请求签名、不创建或解锁 Vault。提交、失败、关闭与页面撤销继续沿原规则清除输入和字节缓冲。私钥／口令保存状态通过完整嵌套消息呈现；Agent 删除确认保留字面用户参数和原确认动作。

本地 Profile 的显示、默认保存／启动前再确认、删除／恢复、参数／空参数、工作目录、环境变量和外观行为编辑已接入；组织管理的分组路径／删除确认、标签／收藏、成员分配和终端配色／键行为继承来源同样使用显式消息。名称、路径、参数和值保持字面数据。语言切换不写入、不改变选择、不删除或启动，原票据与失效处理继续生效；参数／环境变量辅助名称在增删后重新编号。开关使用独立的启用／停用文案，避免与关闭窗口的 Close 混淆。

独立指纹核对覆盖首次、匹配、变更、保存及失败提示；变更密钥仍禁止替换，保存只添加应用指纹记录，不认证或连接。`ssh_config` 的读取预览、IdentityFile 数量提示、源文件核对、准备导入和保存状态接入同一消息机制。快速连接覆盖地址核对、已有／重复主机、临时目标及连接后保存；语言切换不重读、不准备目标、不保存或批准，仍需用户分别确认。名称、别名、地址、用户名与指纹保留原值，动态多行预览使用真实换行与字面参数。

终端历史分页／查找、链接检查、文件路径复制、粘贴／CLI 确认、响铃、返回最新输出及目录状态已接入 `i18n/terminal.en.ts`；新增命令入口使用 `i18n/commands.en.ts`。历史搜索保留原始状态标识，显示文本不参与命中定位或权限判断；远端历史、链接和粘贴预览保持原文。UI-05 文案开发链已覆盖当前产品入口，完整验收仍保持开放。当前模块化生产脚本不引入额外 i18n 运行依赖；未来 React 视图的 namespace、错误文案组织与本目录保持一致。

keyboard-interactive／MFA 的方法标签、可信应用说明、提交和长度错误已纳入连接目录。GUI 连接选择和 CLI 冷暖原窗口批准共用显式方法提示。服务器名称、说明、问题不翻译、不解释为 HTML；按 echo 指定的原输入控件在语言切换时保持值与焦点，切换不回答、不保存、不替换方法。显式提交、Esc／原生 dialog 关闭与请求取消会结束等待并清除输入；仅账号元数据可选择 MFA，但初始不自动选用。

## 开发验证边界

针对语言存储与真实文件重开、v15／旧版本协议、占位符和字面用户数据、页面撤销执行局部检查；复用受影响组件测试。首批收据位于 `target/probes/workspace-language-development/`。SSH 双语批次复用七组直接测试，Chrome 用生产 HTML／样式／控制器与模拟 I/O 检查保存／重开、失败失效、草稿／焦点、批量删除、逐跳指纹与拒绝、英文文案／ARIA 遗漏和三处 390px 布局；收据位于 `target/probes/ssh-language-development/`。长指纹通过换行显示完整值，弹窗采用 border-box，避免窄窗口横向溢出。

身份与 Vault 批次复用五组 50 项直接测试，包含密码／私钥清除、失效表单、旧页与迟到响应及翻译占位符；Chrome 的 25 项组件检查使用生产弹窗／样式／控制器与模拟依赖，覆盖语言切换、草稿／焦点、显式保存与清除、Vault 状态、错误重读、Esc 与迟到响应、英文正文／ARIA、四种 390px 表单。Agent 长指纹完整换行，三处敏感弹窗采用 border-box；收据位于 `target/probes/identity-vault-language-development/`。模拟状态不建立真实加密、持久化或 Agent／SSH 互通结论。

Profile／组织批次复用八组 56 项直接测试，包含默认启动重新确认、生命周期、编辑器和组织协议，以及关闭动作与开关选项词义的回归检查。Chrome 的 40 项组件检查覆盖模拟保存重开、字面参数／空参数／路径／环境变量、草稿／焦点、删除恢复后果、来源与空覆盖、失败显式重读、Esc／迟到响应、英文正文／ARIA和 390px 外层及内部字段区／动作组。Profile／组织弹窗统一 border-box，按钮按项换行，避免内部横向滚动。收据位于 `target/probes/profile-organization-language-development/`；没有扩大 Rust／PTY／真实网络矩阵，沿用现有 CI 测试发现与产品构建。

指纹／导入／快速连接批次复用五组 43 项直接测试。Chrome 的 34 项组件检查使用生产 HTML／CSS／控制器和模拟 I/O，覆盖语言切换不写入或确认、字面名称和指纹、首次／匹配／变更状态、Esc 与迟到响应、源文件变更、导入准备与显式保存、已有／重复主机、临时目标、连接后保存失败不重试、英文正文／ARIA及四处 390px 内外层布局。四处弹窗使用 border-box，动作按项换行。收据位于 `target/probes/connection-language-development/`；不建立真实文件导入、信任持久化、SSH 网络或原生 WebView 结论。

终端／目录批次执行 117 项直接测试与类型检查；Chrome 的 26 项组件检查覆盖历史查找、链接／路径、粘贴与 CLI 确认、响铃和返回最新输出，切换不改变字面内容、不重读或授权。命令面板扩展和键位边界另有 77 项直接检查及 8 项原生目录检查；计数有重叠，不累计为总回归数。Linux 实窗集中验收发现 Vite 会移除空 nonce 样式标记，已通过后置 HTML 钩子保留；另修复已确认布局成功后旧连接已撤销导致 detach 拒绝被误判的恢复失败。最终非诊断构建的真实 WebView 通过终端输入和面板→快捷键→设置→终端返回，严格 CSP 与原输入权限不变；未确认或畸形布局回执仍失败。

组件证据不代替原生 WebView、辅助技术、真实系统菜单、物理键盘／IME 或跨平台验收。没有改终端解析、网络、SSH 鉴权或凭据路径，不重复相应矩阵。
