# 分组与 SSH 入口的终端行为覆盖

TERM-18 的分组／SSH 入口覆盖通过组织编辑窗口交付：进入“分组终端配色与行为”或“SSH 入口终端配色与行为”，可统一修改终端配色、TERM、Option／Meta、Backspace 和 Delete，也可逐项选择继承。五项在一次保存中提交，返回后重新读取组织目录；不授予 SSH 连接或终端输入权限。

## 继承与保存

有效顺序为内置默认值 → 用户设置 → 当前直属分组 → SSH 入口。分组编辑显示默认值／用户设置作为基值；入口编辑还叠加当前直属分组。祖先分组不额外叠加，临时 SSH 目标只采用全局设置。入口作用域使用已保存 SSH 入口 ID，不从前端接收任意组作为连接参数。

五项都是封闭值：配色使用共享目录的十套预设（包括 `classic`／`midnight`／`paper`）；TERM 为 `xterm-256color`／`xterm`／`vt100`；Option／Meta 为布尔；Backspace 为 `del`／`bs`；Delete 为 `csi`／`del`。显式 false 与继承分开。组织行为投影升级为 v2；保存必须包含全部五个字段，显式 null 恢复继承；缺字段、旧 v1 投影、未知字段或非法值拒绝。恢复只移除本作用域对应覆盖，保留同条设置记录的历史容量等其他字段。全局设置投影仍为 v12。

窗口只持有不透明票据。原生核对实际 WebView、当前页和票据种类；同页新读取会替换旧票据，离页或窗口退出撤销旧票据。请求与响应都绑定编辑器构造时的原始 nonce，中途换页不发布旧响应，也不借用新页权限继续保存。读取或保存失败后只能重新读取，不能继续提交旧表单；重复点击不会产生并行保存。

字段使用稳定的可访问名称；当前值与继承来源作为关联描述，保存后重新读取不会改变字段名称。组与 SSH 入口的配色行为动作分别明确标出作用域。

共享 SQL worker 在一个事务内读取组织归属和组／入口设置。保存重新校验组织源、成员关系与两层设置版本，并在提交前再次检查授权；源变化、撤销或冲突回滚。后台 I/O 持有既有 Profile 服务容量直到实际任务退出。用户 settings.toml 与 SQL 是不同一致性域：全局基值通过一次受监督读取捕获，不声称它与 SQL 组成跨文件原子事务。

## 新建会话与刷新

GUI、CLI 的保存入口直连及跳板叶终端，在网络启动前通过原窗口监督路径读取覆盖。全局配色、TERM 和历史容量来自同次全局读取，再将包括配色的五项作用域配置叠加后一次冻结；中间跳板不请求终端。密码、私钥和 Agent 共用该终端初始化，临时目标不应用保存入口覆盖。配色由后端初始基色传递并进入既有捕获／恢复流程，前端不会根据作用域元数据在线改色。

三项按键偏好以私有外观数据随认证完成的协议 parts、父连接清理尾部和 Root 注册传递；密码认证也通过 parts 的统一 `commit` 交接，避免拆出句柄和 native join 时遗漏行为元数据。Root 回收保留活跃协议 owner 和仍在实际清理中的协议记录，确认物理回收后才清除对应外观。刷新恢复使用该会话冻结的值，后来修改全局设置不会使该 SSH 会话改用另一套按键行为。TERM 只用于新终端 PTY 请求；已有会话不会在线改变 TERM 或接收新的作用域配置。Shell Profile 的本地会话覆盖继续沿[原有规则](terminal-behavior.md)，不将 SSH 入口覆盖套用到本地终端。

按键最终仍经过 xterm 的公开选项／输入接口、组合输入保护及原有输入授权队列。目录、设置读取和外观恢复都不建立输入权限，也不改变凭据、指纹或 Vault 授权。

## 开发验证范围

`mise run probe-workspace-ssh-settings` 已通过 Linux 生产 WebView／真实 loopback SSH 密码会话：核对全局 → 直属组 → 入口的按键／前景色优先级、清除入口及组覆盖后的逐级恢复、原会话冻结、刷新不重连和保存零连接；五条原生连接与 GUI 全部退出，其他数据库内容保持不变。按键证据为远端原始字节，颜色证据为 OSC 10 前景色。收据 `target/probes/workspace-ssh-settings-result.json`、组行为和恢复全局截图已归档，正式任务及 Linux CI 已接入。其他字段、系统外观、macOS Option／IME、外部网络和跨平台仍待验收。

本次扩展同一五连接原生场景以核对远端实际 PTY TERM 请求：全局 `xterm-256color` → 直属组 `xterm` → 入口 `vt100` → 清除入口恢复 `xterm` → 清除组恢复 `xterm-256color`。每次保存先核对持久化枚举；切换旧会话、修改设置和刷新必须不新增 PTY 请求。夹具仅在 `PULSE_SSH_SCOPE_PROBE` 下允许上述封闭 TERM 集合，其他任务仍仅接受原默认值；尺寸范围保持原限制。Python 语法、Rust 格式、生产构建及完整五连接实窗已通过；版本2收据记录精确远端序列，修改设置、重新选择和刷新均未重发 PTY，五条连接及 GUI 全部退出。

四项后端直接检查覆盖组到入口继承、显式 false、逐项恢复及其他字段保留、组版本／成员关系变化拒绝、取消与提交前撤销回滚，以及注册会话按键偏好冻结。新增缺字段拒绝断言放入已有检查，未增加全量回归。11 项受影响前端行为包括封闭投影、组织目录既有行为和冻结偏好恢复。

一次 Chrome 组件检查通过受控原生适配覆盖组／入口表单、单次提交、重复抑制、冲突后重新读取、旧 nonce 响应丢弃、返回入口及 720px 布局。它不访问真实设置数据库或进行 SSH 认证，不能替代原生 WebView、真实 PTY／SSH、macOS Option／IME 或跨平台验收。

类型、产品构建、格式、局部 Biome 及 Store／App／桌面库严格 Clippy 已通过；新增 Store 模块 Astrolabe 诊断为 Exact 零问题。Biome 保留组织编辑器原有的五项信息警告。最终日志与清理收据见 `target/probes/scoped-behavior-development/`。沿用现有 CI，不增加重型矩阵。
