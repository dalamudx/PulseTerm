        命令面板

          设置

          界面外观保存后立即应用；终端配色和历史容量用于新建终端，其他终端设置在下次显示时应用。

          快捷键

          SSH 主机

          管理连接目标。不保存凭据，不修改主机指纹信任，也不启动 SSH 连接。

          SSH 配置

          为 SSH 入口保存独立的配置名称、登录用户名和默认身份。

          分组、标签与收藏

          将主机和身份按分组、标签整理，并标记收藏。

          预览 ssh_config

          读取本机 SSH 配置，核对连接参数后可保存为主机。IdentityFile 仅提供数量提示，凭据需另外选择。

          快速连接 SSH

          核对地址后可临时连接，连上后选择保存。也可先保存或使用已有主机，再选择身份并确认连接。
