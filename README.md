# PulseTerm

基于 Rust、Tauri 2 和 React 的跨平台终端与远程连接工作台。

## 开发

使用 [mise](https://mise.jdx.dev/) 管理工具链：

```sh
mise trust .mise.toml
mise install
mise run bootstrap
mise run check
mise run test
mise run probe
mise run audit
```

开发环境、产品状态与验证方式见[文档索引](docs/README.md)。
